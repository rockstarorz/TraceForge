# 展示素材

- `traceforge-preview.webp`：GitHub 首页循环预览，画面来自 V5 成片。
- `traceforge-video-cover.jpg`：宣传视频封面。
- 最新完整宣传片：V6 BGM5 音轨版，随 `app-v1.0.1` GitHub Release 发布，不放入 Git 历史，避免源码克隆体积持续膨胀。

完整演示约 62.5 秒，包含日志自动解析、分类时间轴、定位状态、卫星趋势、未上报区间、告警定位、选区轨迹与 Google Earth。剪辑用于展示可验证功能，不以视频时长代表软件性能。

视频音轨由作者提供。鼠标点击和转场声来自 Mixkit 素材，遵循 [Mixkit License](https://mixkit.co/license/)。地图画面使用 Google Earth，并保留素材中的地图署名。
